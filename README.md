1. What is the difference between var, let, and const?
   ans:
   
var:

a. Old JavaScript variable declaration
b. Function scoped
c. Can be re-declared

let:

a. Block scoped
b. Can be reassigned
c. Cannot be re-declared

const:

a. Block scoped
b. Cannot be reassigned
c. Value must be given when declaring the variable

2.  What is the spread operator (...)?
    Ans:

The Spread Operator (...) is used to expand the elements of an array or object.
It is commonly used to copy, merge, or clone arrays or objects.


3.  What is the difference between map(), filter(), and forEach()?
Ans:

map():
a. Works on each element of an array
b. Returns a new array

filter():

a. Filters elements based on a condition
b. Returns a new array

forEach():

a. Only runs a loop on each element
b. Does not return a new array
